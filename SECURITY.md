# Security

Clipt runs entirely on your Mac and doesn't talk to any server, but it does
handle screen, microphone and camera access, so security reports are taken
seriously.

## Reporting a vulnerability

Please don't open a public issue. Instead, use GitHub's
[private vulnerability reporting](https://github.com/eduardoalba00/clipt/security/advisories/new)
for this repository. Include what you found, how to reproduce it, and the
macOS and Clipt versions involved.

You'll get a reply within a week. Once a fix is ready, it will be released and
the advisory published, with credit to you if you'd like.

## Supported versions

Only the latest release receives security fixes.
